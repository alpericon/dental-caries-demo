Ground truth — labels from the training datasets (dentist-annotated).    Model prediction — this model's own output on the same, unmodified image, drawn on top so mismatches are easy to spot.
These are held-out images the model was not trained on, randomly sampled from the full validation set on every reload — not a curated set picked to look good. A prediction counts as a match when it overlaps a ground-truth box by IoU ≥ 0.5 — the same threshold behind this project's mAP50 metric.
